# Detrender regression fixtures

`detrend-basic-data.csv` retains the original 1,830 timestamp/input pairs.
Its expected outputs are generated by the independent double-precision scalar
model in `tools/detrend_reference.py`: default baseline fraction 0.35, frequency
smoothing time constant 13 s, measured-period weighting, logarithmic frequency
averaging, and one cleanup stage. The C++ regression tolerances are unchanged.

Verify without modifying the fixture:

```sh
python3 tools/detrend_reference.py
```

Only after reviewing an intentional algorithm/default change, regenerate the
expected columns with `python3 tools/detrend_reference.py --write`. CI never
uses this write mode. Validation pins the original input-pair SHA-256, and
`detrend-log-frequency-test` separately checks both scalar and 3D frequency
updates against the closed-form log EMA for internal and external guidance.
