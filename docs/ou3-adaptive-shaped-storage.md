This note is subordinate to `docs/ou3-shipping-faithfulness-protocol.md`.
It does not change estimator behavior or assumptions. The target is a shipping-level

## 1. Exact generated normalization

At sample k let the *applied* shipping tuner tuple be
`(tau_k,sigma_k,R_S,k,T_S,k)`, generated by the one-sample-causal frontend/tuner
history. Define, axiswise,

    y_k = D_k x_k,
    x_k = (v,p,S,a_w),
    D_k = diag(1/(sigma_k tau_k),
               1/(sigma_k tau_k^2),
               1/(sigma_k tau_k^3),
               1/sigma_k).

No independent extrema of these quantities are admitted.

For one prediction with h_k and x=h_k/tau_k, the literal shipping transition
from IntegratedOUChain<T,3> gives exactly

    y^-_{k+1} = Fbar(x) y^+_k

when the same applied tuple spans the prediction, with

    Fbar(x) =
      [1, x, x^2/2, f_v(x);
       0, 1, x,     f_p(x);
       0, 0, 1,     f_S(x);
       0, 0, 0,     exp(-x)],

after ordering coordinates as (v,p,S,a_w), where
f_v=1-exp(-x), f_p=x+expm1(-x), and
f_S=x^2/2-x-expm1(-x). The small-x shipping polynomial branches are retained
literally when constructing a certificate; this displayed exponential form is
the exact-real branch identity.

Thus the frozen-tuple homogeneous chain has no independent tau or sigma
uncertainty: it is a one-parameter dimensionless family indexed by the actual
x=h/tau.

## 2. Causal tuner commit is a multiplicative coboundary, not uncertainty

If the tuner commits between two physical samples, the normalized coordinates
change by the exact diagonal map

    C_k = D_{k+1} D_k^{-1}
        = diag(q_sigma q_tau,
               q_sigma q_tau^2,
               q_sigma q_tau^3,
               q_sigma),

where q_sigma=sigma_k/sigma_{k+1} and q_tau=tau_k/tau_{k+1}.

These ratios are NOT free boxes. They are generated by the literal frequency/
variance filters, EMA recurrences, clamps and one-sample staging. The shaped
storage must carry C_k jointly with the same measurement history that generated
the following Fbar, R_S and T_S. Over a complete word the pure coordinate
changes telescope: D_N Phi D_0^-1. Bounding every C_k separately would destroy
this coboundary and is prohibited unless explicitly labelled a relaxation.

## 3. Literal S=0 correction in normalized coordinates

For an accepted S pseudo-measurement, retain the actual covariance-derived gain
K_S,k. In normalized coordinates its homogeneous factor is

    Abar_S,k = D_k (I-K_S,k H_S) D_k^-1,

and its affine/source term is transformed by the same D_k. The pair
(Abar_S,k, source_k) must be kept together. R_S,k and T_S,k are generated from
the same tuner history. For deployed SpectralMSE,

    R_S = C_J q_eff^(1/14) sigma_aB^(6/7) tau^(24/7) / sqrt(T_S),
    sigma_aw = c_sigma sigma_aB,
    T_S = clamp(c_T tau),

    R_S/(sigma_aw tau^3)
      = const * sigma_aB^(-1/7) tau^(-1/14).

This weak normalized dependence is the candidate reason the S/AW feedback can
admit a uniform shaped energy over the shipping-reachable tuner family. Clamp
branches must be handled as literal generated branches, not independent limits.

## 6. Removal of the common-Q and separated-LIN restrictions

The carried diagnostic no longer requires a block-diagonal/scalar storage on
(v,p,S,a_w), and no longer requires one Q across sea states.  At a generated
shipping endpoint define

    Pbar_k = D_k P_k D_k',
    Q_k = Pbar_k^-1.

all v-p-S-a_w covariance/storage cross terms generated by literal prediction,
S=0, accelerometer corrections and covariance synchronization.  Because D_k is

storage.  Root and terminal Q are therefore allowed to differ along the one

    rho_W = lambda_max(Q_0^-1/2 Mbar_W' Q_N Mbar_W Q_0^-1/2).

This is still only a finite carried diagnostic.  A rho_W failure is class D:
the selected generated covariance metric did not certify contraction.  It is
not a shipping counterexample.  The source-uniform theorem must subsequently
enclose the reachable generated storage family and add physical supply/prefix
retention.

Structures preserved: full 12x12 LIN coupling; generated-state-dependent
storage; literal covariance and gains; joint tuner history; chronology and

Relaxations introduced: finite carried histories only.  No independent tuner
