## Current limiter

The complement endpoint ratios are below one at both difference scales, but
the whitened operator discrepancy is about 142 times the available norm
margin. Classification: unresolved sensitivity conditioning and finite-error
supply, not an estimator regression or an instability result. The discrepancy
is **not** a rigorous error bound; it neither certifies nor disproves the true
matrix inequality. The invalidated hypothesis is that the positive measured
margin alone is ready for a rigorous contraction enclosure.

The isolated bias gain does not cover reference forcing or the nonlinear
remainder. No practical error radius follows from it. Time-varying covariance
is material on the complement, as the frozen-metric result shows. Uniform
coercivity and inheritance of covariance/frontend/tuner state remain required.
Capture, hard-event retention, release, A21, recurring service and arithmetic
obligations remain open. No theorem completion flag is changed.

## Failed approaches / DEAD_ENDS

Strict full-state H18 contraction is obstructed by the same-history identity
bias block on feasible held segments. Do not spend enclosure effort on that
formulation. A held estimator prior is not a physical-bias law: absolute bias
error is not constant when true bias changes. Local differences about a
nonzero reached error are not the exact nonlinear homogeneous map. A prefix
profile along one endpoint direction is not an all-direction retention bound.
Post-correction transport with pre-correction innovation covariance is not the
specified magnetic information. Approximate identity within a tolerance is
not an exact non-contraction proof.
