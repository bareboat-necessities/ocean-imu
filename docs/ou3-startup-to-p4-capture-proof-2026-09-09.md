# OU-III shipping startup -> P4 capture proof

Status: **OPEN / FAIL-CLOSED**.  This document states the theorem that is now
being proved by PR #512.  It deliberately does not equate `goLive()` with P4
capture and does not use covariance confidence as a true-error set.

## 1. Target theorem

For every explicitly admitted initial condition, COMPLETE-BRMM physical motion
history, BIAS0/BIAS1/BIAS2 history, declared measurement/model disturbance and
finite-precision realization, the shipping estimator must reach a certified
P4-H18 Live section in finite time.  From that section, every allowed Live word,
adaptation event, Joseph update, radial projection, reset and H18->A21 release
must preserve the nonlinear domain and yield regional practical ISS of the 18
motion-error states with bounded accelerometer-bias error indefinitely.

The proof is therefore the composition

```
STARTUP_REACHABLE_TUBE
  -> SHIPPING_LIVE_HANDOFF_FIBER
  -> EARLY_LIVE_H18_CAPTURE_TUBE       (needed by timeout handoff)
  -> P4_H18_INVARIANT_BASIN
  -> H18_TO_A21_HYBRID_MAP             (when release occurs)
  -> P4_A21_INVARIANT_BASIN.
```

P4 is the invariant Live stability theorem.  P5 is the finite-time reachability
argument whose terminal section is P4 membership; P5 may extend past the
shipping `goLive()` call when the timeout path hands over before the tuner or
magnetic gauge is ready.

## 2. Executable shipping handoff audit

The shipping front end advances the private Mahony observer, WPE, sigma band,
tuner and related measurement-only state with `drive_mekf=false`.  The MEKF
therefore does not propagate before handoff.  Its constructor zeros the full
state, while independently seeding covariance.  At `goLive()` the attitude and
its covariance block are initialized; `enterLive_()` commits the current OU
operating point and reseats the `a_w` covariance marginal, clearing its cross
covariances.  It does not rewrite the linear state values.

Consequently the estimated linear state presented at the first Live sample is

```
v_hat = 0, p_hat = 0, S_hat = 0, a_w_hat = 0.
```

Those equalities do **not** imply four zero estimation errors.

Choose the natural handoff-local translation gauge at handoff/capture time
`t_h`:

```
p_true^h(t) = p_phys(t) - p_phys(t_h),
S_true^h(t) = integral_[t_h,t] p_true^h(s) ds.
```

Then at the handoff itself

```
e_p(t_h) = 0,
e_S(t_h) = 0,
e_v(t_h) = v_true(t_h),
e_aw(t_h) = a_w,true(t_h).
```

The velocity and latent-acceleration coordinates therefore remain SAME-BRMM
physical source coordinates.  They may not be zeroed merely because the filter
state is zero.

Covariance is not used to establish any of these true-error equalities or
bounds.

## 3. Correction of the legacy 300 m*s entrance factor

The former P4 entry product set admitted an independent
`||e_S|| <= 300 m*s` factor and an independent position-error factor.  Those
are not generated by the shipping handoff described above.  They are now
removed from the **entrance** fiber.

This does not assert that `S` or `p` remain zero in Live.  The old finite
translation radii remain conservative **working/prefix** capacities while the
filter propagates and receives the actual `S=0` Joseph events.  Thus P4 can
prove bounded excursions without inventing an impossible startup uncertainty.

The affine hard-tube proof primitive now permits radius zero exactly.  For a
selector `E`, the homogeneous constraint

```
-||E x||^2 >= 0
```

is exactly `E x=0`; no epsilon-radius replacement is used.

The historical frozen-map 4.5788 H18 diagnostic is therefore evidence that the
legacy independent `S` entry factor destroys that certificate, not evidence of
shipping-filter instability.  Its correct use is to motivate the reachable
entry audit above.

## 4. What the private Mahony observer actually proves so far

The shipping proxy is `VerticalAccelComplementary`, wrapping the binary32
`Mahony_AHRS<float>` recurrence with `two_kp=0.2`, `two_ki=0.02`.  It is seeded
from the first valid accelerometer direction; yaw is unobservable in the proxy
and only its tilt has physical meaning until a magnetic gauge is supplied.

For physical specific force

```
f = -g d + a,      ||a|| <= A < g,
```

the maximum possible first-sample tilt-direction error is the tangent angle

```
theta_0 <= asin(A/g).
```

With the declared `A=4 m/s^2`, `g=9.80665 m/s^2`, this is approximately
`24.072136 deg`, strictly inside the declared 60 deg Mahony chart before the
separate sensor and binary32 direction-error charges.

That is only an initialization lemma.  It is **not** a 150 s capture proof.

The existing private-Mahony interval module exactly encloses one shipping
binary32 update and proves finite arithmetic/norm bounds.  Its previous
"150 s Live-entry" argument, however, uses the declared 60 deg Mahony chart to
show that the timeout gravity branch remains positive.  Such an argument is a
conditional chart-retention result, not a proof that startup dynamics reach or
stay in that chart.  The end-to-end theorem therefore does not consume that
step as capture.

## 5. Quality and timeout handoff are different theorem branches

The normal quality handoff requires simultaneously:

* initialized proxy;
* minimum startup time;
* gravity trust;
* magnetic north when a magnetometer is configured; and
* tuner readiness.

The timeout handoff at the deployed 150 s ceiling requires an initialized proxy
and the aligned gravity branch, but does **not** require magnetic north or tuner
readiness.  Hence a valid theorem cannot demand final-tuner/full-heading P4
membership exactly at every `goLive()` call.

There is an additional gate-memory issue.  The shipping gravity-good counter is
capped at 10 s and, on a bad sample, decays by 2 s of credit per elapsed second.
The required hold is 2 s.  From a saturated counter, `gravity_trusted` can
therefore remain true for up to 4 s after the last good gravity sample.  A
quality handoff cannot be converted directly into an instantaneous
`sin(theta)<=0.075` constraint.  The source-uniform Mahony proof must propagate
through this complete leaky-hold tail.

## 7. Current source-admission gap

The declared Normal-Live domain contains a magnetic/vector PE recurrence, but
that is not yet a proof of startup magnetic acquisition or tuner capture.  The
current COMPLETE-BRMM source machinery also still reports its global finite
source-family materialization as open.  Therefore finite quality-handoff for
every admitted startup history is not presently established.

This is failure class **E/F**, not a demonstrated nonlinear instability:

* **E:** startup COMPLETE-BRMM/source/observability qualification is incomplete;
* **F:** the exact shipping proxy/early-Live finite-time capture implication is
  incomplete.

If an admissible BRMM history truly permits indefinite loss of information
needed for north/tuner acquisition, the theorem may add only the weakest
physical recurrence/excitation condition needed to exclude that history.  It
may not exclude a sea state merely because its proof cell is inconvenient.

## 9. Basin maximization and capture overlap

Once a first P4 certificate closes, its entrance is not frozen at the first
successful numerical radius.  The proof search must enlarge the physically
reachable correlated basin until an actual limiting certificate boundary is
identified for attitude, gyro bias, velocity, position, S, latent acceleration,
accelerometer bias, tuner/adaptation state, covariance and scheduler state.

P5 then proves that every admitted startup/early-Live tube intersects this
largest defensible P4-H18 basin in finite time.  The desired final output is a
certified uniform `T_capture_max`; if only source-dependent bounds arise, their
supremum over the admitted source family must be finite and explicit.
