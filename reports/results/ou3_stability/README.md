# OU-III stability evidence

This directory contains the current fail-closed theorem status and source provenance binding the proof to the shipping estimator.

The evidence is intentionally not a completion certificate. A finite replay cannot certify the all-time wave-displacement primitive or recurring magnetic information by itself.

Regenerate the machine-readable validation report with:

    python3 tools/stability/ou3_theorem/build_evidence.py --output /tmp/ou3-stability-evidence.json
